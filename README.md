# 习惯花园 · 打卡助手

把坚持种成一座花园：每天打卡照料植株，攒花露经营苗圃，用植物的全生命周期映射习惯的养成、中断与恢复。

一个**纯前端、零依赖、无构建步骤**的静态网页应用——文件夹里的文件是什么，浏览器里跑的就是什么。

## 功能一览

- **习惯打卡**：多习惯并行，支持每天 / 工作日 / 周末 / 自定义星期几；打卡日以凌晨 5 点为界
- **植株生命周期**：种子 → 发芽 → 生长 → 含苞 → 盛开 → 毕业 → 升阶 / 收获；漏打卡会枯萎，连续照料可复活，连续枯萎三次永久死亡
- **花园地图**：正面平视的 9×9 苗圃网格，植株直接种在草坪上；装满自动开辟新地图，支持多地图切换与删除
- **小动物园丁**：蜗牛 / 瓢虫 / 蜜蜂等 8 种，购买后会出现在植株旁帮忙浇水 / 施肥 / 除虫
- **经营系统**：打卡产出花露；商店出售 40 种植物、园丁、照料道具、花园装饰、地图皮肤
- **数据统计**：每习惯 12 周打卡日历、花露收支报表、园丁名册
- **每日提醒**（可选）：到点有未完成的打卡时弹浏览器通知
- **PWA**：可通过浏览器「安装」为独立应用，离线可用

## 文件结构

```
习惯养成打卡助手/
├── index.html        页面结构：所有对话框、花园覆盖层、列表容器
├── app.js            全部逻辑：打卡、经济、植株生命周期、商店、地图渲染、提醒
├── plants.js         数据图鉴：40 种植物（含花语文案）、动物、道具、装饰、皮肤
├── styles.css        全部样式（含手机端适配）
├── sw.js             Service Worker：网络优先、离线兜底的缓存策略
├── manifest.json     PWA 清单：应用名、图标、主题色
├── icon-192.png      应用图标（PWA 用）
├── icon-512.png      应用图标（PWA 用）
├── .zcodeignore      ZCode 工具的搜索过滤配置（与网页无关，部署时可跳过）
└── README.md         本文件
```

各文件职责单一、互相独立：改植物数据只动 `plants.js`，改样式只动 `styles.css`，逻辑全在 `app.js`（文件头部注释列明了核心规则）。

## 本地运行

三种方式，按需选择：

1. **直接双击 `index.html`** —— 最快，功能完整；仅浏览器「安装为 PWA」不可用（见下方已知限制）
2. **本地 HTTP 服务**（推荐，体验最完整）：

   ```bash
   # 任选其一，在本文件夹内执行：
   python -m http.server 8931        # Python
   npx serve .                       # Node.js
   ```

   然后浏览器访问 `http://localhost:8931`
3. **任意静态文件服务器** —— 本项目是纯静态站，nginx / Caddy / 各类对象存储静态托管均可直接托管

## 数据存储

- 所有数据（习惯、打卡记录、花露、购物）保存在**浏览器 localStorage** 中，按「浏览器 + 域名」隔离
- **不同浏览器、不同设备之间的数据互不相通**；换设备请使用「⚙ 数据管理 → 导出备份」，在目标设备「导入备份」
- 没有服务器、没有账号体系——数据 100% 存在本地，隐私安全，但也意味着清除浏览器数据 = 清空花园

## 视觉风格

整体为**旅行青蛙式手绘水彩风**：奶油纸色底、圆体字（站酷快乐体，联网时自动加载、离线落回本地圆体）、所有图标为统一笔触的线性描边、植株与装饰为代码手绘 SVG。配色集中在 `styles.css` 顶部的 CSS 变量中，想微调色调只改变量即可。

## 已知限制（部署前必读）

1. **HTTPS 依赖**：Service Worker（离线缓存 / PWA 安装 / 每日提醒通知）是浏览器安全特性，只在 `localhost` 或 **HTTPS** 下生效。
   - 用 `http://公网IP` 部署后：页面功能完整可用，但 SW 不会注册、无法安装 PWA、通知不弹
   - 想恢复这三个能力需要域名 + HTTPS 证书（如 Caddy 自动签发、certbot 等，属部署进阶内容）
2. **无后端**：多访客各自有独立的 localStorage，数据不共享、不同步。如需云端同步，需要引入后端服务与账号体系（超出当前 1.0 范围）
3. **localStorage 容量上限**：约 5MB（按浏览器不同略有差异），按本项目数据量可使用数十年，无需担心

## 部署

本项目为纯静态站，部署 = 把文件夹里的文件放到任意能提供 HTTP 服务的环境。

常见路径（以学习为目的推荐按顺序尝试）：

1. 本地验证：`python -m http.server` 后浏览器访问
2. 容器化：编写 Dockerfile（推荐 `nginx:alpine` 基础镜像，仅需 COPY 文件 + 声明端口）
3. 云服务器：SSH 上传 → 构建镜像 → 运行容器 → 配置端口映射 → 公网 IP 访问

> 具体的 Dockerfile 编写是练习内容，不在本 README 中直接给出答案。
